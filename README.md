## Adding A New Article

1. Create a new markdown file in `articles/` named with a URL-friendly slug, for example `articles/my-new-article.md`.
2. Add front matter:

```md
---
layout: default
title: My New Article
description: One-sentence summary of the article.
permalink: /articles/my-new-article
---
```

3. Write the article content below the front matter in Markdown.
4. Add a link to the article in both `index.md` (homepage `## Articles` section) and `articles.md` (articles index page).
